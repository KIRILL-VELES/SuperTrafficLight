# SuperTrafficLight

A simple iOS application demonstrating a traffic light with red, yellow and green lights.

## Requirements
- Xcode 14 or later
- iOS 16.0 or later

## Usage
Open `SuperTrafficLight.xcodeproj` in Xcode and run the application on the simulator or device. Tap the button to cycle through the lights.
